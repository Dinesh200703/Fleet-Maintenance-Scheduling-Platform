# Fleet Maintenance Scheduling Platform

## 1. Project Title

**Fleet Maintenance Scheduling Platform**

---

# 2. Problem Statement

Managing a fleet of vehicles using manual records or spreadsheets is time-consuming, error-prone, and inefficient. Organizations often face difficulties in tracking vehicle details, scheduling preventive maintenance, monitoring maintenance history, and ensuring timely servicing of vehicles.

Without a centralized maintenance management system, organizations may experience:

- Missed maintenance schedules
- Increased vehicle downtime
- Poor maintenance tracking
- Manual data entry errors
- Higher operational costs
- Reduced fleet efficiency

To solve these challenges, a web-based Fleet Maintenance Scheduling Platform is developed to simplify vehicle management and maintenance scheduling.

---

# 3. Proposed Solution

The proposed system provides a centralized platform for managing fleet operations through a secure web application.

The system allows administrators to:

- Register and authenticate users securely.
- Manage vehicle information.
- Schedule vehicle maintenance.
- Update maintenance status.
- View fleet statistics through a dashboard.
- Store all data in a centralized MySQL database.

The application follows a modern client-server architecture using React for the frontend and FastAPI for the backend.

---

# 4. Objectives

The primary objectives of the project are:

- Develop a secure login system using JWT authentication.
- Maintain vehicle information efficiently.
- Schedule preventive maintenance.
- Reduce manual maintenance tracking.
- Improve fleet monitoring through a dashboard.
- Provide a scalable and modular architecture.
