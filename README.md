# 🚛 Fleet Maintenance Scheduling Platform

> **Smart Fleet Management | Preventive Maintenance | Real-Time Dashboard**

A full-stack Fleet Management System designed to streamline vehicle maintenance, reduce downtime, and improve operational efficiency through smart scheduling and automation.

---

## ✨ Features

- 🔐 Secure JWT Authentication
- 🚗 Vehicle & Driver Management
- 🛠️ Maintenance Scheduling
- 📋 Service History Tracking
- 📊 Dashboard & Analytics
- 📧 Email Notifications
- ⚡ RESTful APIs
- 📱 Responsive Design

---

## 🛠️ Tech Stack

| Frontend | Backend | Database | Authentication |
|----------|----------|----------|----------------|
| React + TypeScript | FastAPI (Python) | MySQL | JWT |

---

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/your-username/Fleet-Maintenance-Scheduling-Platform.git

# Backend
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload

# Frontend
cd frontend
npm install
npm run dev
```
